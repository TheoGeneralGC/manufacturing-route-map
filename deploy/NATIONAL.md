# National map data flow

`npm run build` prefers `data/national/manifest.json`: ordered `parts` with basename `name`, compressed-file `sha256` and `records`, plus `total_records` and `data_sha256` over the concatenated decompressed bytes. Parts are streamed in manifest order and both individual and total counts/hashes are checked. It falls back to `data/plants.jsonl.gz`, then the former `plants.json.gz` JSON array for small/legacy fixtures. Each record requires a stable `id` and explicit state.

The builder writes compressed full-record batches and compact search shards inside the Vercel function. Repeated values are dictionary encoded, search shards are partitioned by state, and a small catalog lets geographic, state, exact city/county and ZIP searches load only relevant states. Generic business/type searches retain a full-country path. ID hash buckets locate selected full records without loading the search index. Only UI files, the version-2 manifest and coverage metadata are directly allowlisted. Internal record batches, lookup files and indexes are not public paths. Total function storage is limited to 230 MB; each HTTP response is limited to under 4 MB. The function requests 2 GB memory and a 60-second maximum duration.

The read-only `/outreach-map/api/query` endpoint searches the compact index. It supports text, state, county, industry, evidence, employee bands, quality, reported operating status, owner/contact availability, source, optional GPS radius, optional map bounds, and ID selections for browser-local saved/visited records. Exact city/county searches accept a state code after a comma. Five-digit and ZIP+4 searches match ZIP fields. Historical records are hidden by default.

Each response includes accurate full-match counts, one bounded result page (80 normally, server maximum 100), match bounds, and at most 1,200 viewport features. Dense features aggregate counts and employee-band distributions; no matching locations are silently dropped from cluster counts. With no destination entered, startup searches the visible map area and labels the result count accordingly. Destination search and location-off can search nationally; GPS requests use their selected radius. The browser stores only pages and bounded map summaries. Full source records, ownership/photos and supplemental headcounts load through `/outreach-map/api/record?id=...` only when needed. CSV export explicitly covers the displayed page and first retrieves its full records. The separately generated Excel inventory holds all rows.

The server stores no user notes or GPS history. Requests are GET/HEAD only, with no cookies or authentication gate. Notes remain in browser storage. Existing canonical IDs remain usable, and `merged_ids` allow saved/visited searches to locate old IDs after a confirmed merge.

Validation:

- `npm test`: API allowlist/security, existing mobile/GPS/employee/Gemini regressions, national search/radius/cluster tests.
- `node qa/mobile-national-smoke.cjs`: optional real 390×844 browser smoke test using this workstation's bundled Playwright/browser. This test creates and closes a temporary HTTP server; it writes screenshots/reports to the research directory.
- `npm run verify`: anonymous production UI/metadata byte checks, national counts, bounded cluster counts, selected full-record equality, Tracy state-aware results, and internal-path denial. Run after deployment.

Measured locally with the draft imported 530,101-row dataset: 188,879,644 bytes of function storage; 195 ms cold initial regional query; 5 ms subsequent Tracy search; 11 ms nearby query; 1.07 seconds for the first whole-country query. Heap was approximately 400 MB and RSS 655 MB after loading the entire country. A 390×844 mobile browser smoke test passed search, details, GPS, radius changes, location-off, state filtering, directions/Gemini, and overflow/error checks. Reports and screenshot are in `../plant-outreach-map/sources/us-manufacturing-import/`. Recheck counts, storage and behavior with the final dataset; these local measurements are not a production latency guarantee.
